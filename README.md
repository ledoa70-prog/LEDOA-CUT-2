# LEDOA CUT 2

새 구조로 다시 만드는 개인용 모바일 영상 편집기.

## 개발 원칙
1. 직관적 UI
2. 심플한 조작
3. 높은 작업 효율
4. 빠른 결과물
5. 끊김 없는 재생
6. 깜빡임 없는 화면 전환
7. 기존 LEDOA CUT 모바일의 얼굴추적 이전 핵심 기능 복원
